01LEARNING EXPERIENCE

Boda Academy

An Arabic learning environment for people finding their way into mobile development.

Open full project ↗

The experience is organized around three learning tracks — Flutter, Kotlin and Dart — with a lesson list, a search field, a collapsible sidebar and a guided progression through the material. 02MARKET RESEARCH CONCEPT

Waave AI

A market-intelligence concept that turns a broad research question into a set of navigable views.

Open full project ↗

The public build brings together an overview, product discovery, trend cards, insight lists, a dashboard, methodology and supporting information pages. Its interface includes client-side filtering, view switching, chart-range controls, language direction changes and hash-based navigation. The implementation is written as a self-contained HTML document with CSS and JavaScript in the page; it also uses GSAP and ScrollTrigger for motion. The code stores the selected language in local storage.

Source review: HTML · CSS · vanilla JavaScript · DOM querying and events · localStorage · filtering · client-side view routing · chart rendering · IntersectionObserver · GSAP / ScrollTrigger.

The site explicitly describes its market indicators as illustrative demo data. It should be presented as a frontend prototype, not a live market-data product.

03FINANCIAL PRODUCT CONCEPT

Payno

A product story for a personal-finance experience, supported by dashboard-style visual language.

Open full project ↗

Payno is structured as a multi-page product presentation with overview, product, insights and how-it-works sections, plus a dashboard route. Its JavaScript handles the mobile menu, a monthly/yearly pricing switch, an accordion that advances while visible, and scroll-aware navigation. GSAP and ScrollTrigger provide the page-motion system, while the code checks the reduced-motion preference and keeps core content visible when animation is unavailable.

Source review: HTML · CSS split across global, motion and responsive files · vanilla JavaScript · event handling · IntersectionObserver · GSAP · ScrollTrigger · responsive layouts · reduced-motion handling.

The page labels its metrics, pricing and testimonials as illustrative. The public code reviewed does not establish a connected banking backend or production payment processing.

04ARABIC RETAIL STOREFRONT

Happy Library

A catalogue-led storefront for gifts, toys, party supplies and school essentials.

Open full project ↗

The home page introduces the shop and directs visitors to a separate Projects catalogue.
